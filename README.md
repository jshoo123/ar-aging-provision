# 매출채권 연령분석 기반 대손충당금 자동화

매출채권 리스트를 넣으면, 채권 발생일 기준 경과일수를 계산해서 연령 구간별로 대손율을 매칭하고 대손충당금을 자동으로 산출해주는 작은 프로젝트입니다.

회계/감사 실무에서 대손충당금은 보통 연령분석(Aging Analysis)을 기반으로 산정하는데, 채권 건수가 많아지면 이 작업이 반복적이고 사람이 하다 보면 실수가 나기 쉽습니다. 그래서 이 과정을 엑셀 수식과 VBA 매크로로 자동화해봤습니다.

## 파일

- `AR_Aging_Provision.xlsx` — 수식(VLOOKUP, SUMIFS)으로 구현한 버전입니다. 매크로 없이 그냥 열어봐도 로직이 시트에 다 보입니다.
- `AR_Aging_Macro.bas` — 같은 로직을 VBA로 짠 매크로 코드입니다. Excel VBA 편집기(Alt+F11)에서 가져오기(Import)하면 쓸 수 있습니다.

엑셀 파일은 시트 3개로 구성했습니다. `AR_Data`에 원천 데이터(거래처명, 채권발생일, 채권금액)가 있고, `Aging_Policy`에 구간별 대손율 정책을, `AR_Aging_Summary`에 실제 계산 결과를 넣었습니다.

## 어떻게 계산하는지

각 채권마다 경과일수(오늘 - 채권발생일)를 구하고, 아래 구간에 맞춰 대손율을 매칭한 다음 채권금액에 곱해서 대손충당금을 산출합니다. 0~90일은 1%, 91~180일은 5%, 181~365일은 20%, 366일 초과는 50%로 잡았습니다.

이 대손율은 시연을 위해 제가 임의로 정한 숫자입니다. 실무에서는 과거 대손 실적률이나 산업 통계, 거래처 신용도 같은 실제 근거로 정해야 하고, 이 가정치가 타당한지 자체도 감사 절차에서 따로 검토할 대상입니다.

## 매크로 쓰는 법

1. `AR_Aging_Provision.xlsx`를 매크로 사용 통합 문서(.xlsm)로 다른 이름 저장
2. Alt+F11로 VBA 편집기 열기
3. 파일 → 파일 가져오기 → `AR_Aging_Macro.bas` 선택
4. `Run_AR_Aging_Provision` 매크로 실행하면 `AR_Aging_Summary_VBA` 시트가 새로 생기면서 결과가 채워집니다

## 겪었던 문제

처음 매크로를 돌렸을 때 경과일수가 큰 채권 몇 건의 대손율이 0%로 잘못 나오는 걸 발견했습니다. 수식 버전(`AR_Aging_Provision.xlsx`)이랑 결과를 비교해보니 차이가 있었고, 원인을 찾아보니 대손율 정책표 옆에 남겨둔 메모 텍스트 때문에 매크로가 표의 마지막 줄을 잘못 인식하고 있었습니다. 정책표 범위를 찾는 기준 열을 바꿔서 해결했습니다.

## 아쉬운 점 / 더 해보고 싶은 것

- 지금은 대손율이 고정값인데, 거래처별 신용등급이나 과거 회수 이력을 반영해서 대손율 자체를 좀 더 정교하게 산정하는 로직을 넣어보고 싶습니다.
